# Heaven Furniture Mart

A premium furniture website built for **Heaven Furniture Mart** as part of the **Racdox Hackathon**.

Designed with a clean visual direction, smooth interactions, and GSAP-powered scroll animations.

### Live

https://heaven-furniture-mart-psi.vercel.app/

### Built With

* Next.js
* TypeScript
* Tailwind CSS
* GSAP
* ScrollTrigger

### Features

* Responsive design
* Smooth scrolling
* Scroll-based animations
* Interactive furniture gallery
* Bespoke furniture showcase
* Premium CTA sections
* Custom preloader

Built for the **Racdox Hackathon**.
